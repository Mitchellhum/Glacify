Validation Model¶

ValidationBase¶

The validator base class helps you define the structure of your validation model.

class glacify.base.ValidationBase(dataframe: DataFrame | None = None, strict: bool | None = None)¶

Base class that is used to define a validator class. The idea of the class is to improve readability of validation code for polars dataframes, while still integrating properly with other pipelines, such as excel file validations.

settings¶

Allows a custom definition of all model-wide settings. Uses all default values is not set by the user.

Type:

ValidationSettings

Examples

>>> from polars import Expr, col, lit
>>> from glacify import ValidationBase, Column, validator, ValidationSettings
...
>>> class ExampleValidator(ValidationBase):
...    settings = ValidationSettings(strict=False)
...    id: int = Column(name="Index")
...    first_name: str = Column(name="First Name")
...    last_name: str = Column(name="Last Name")
...    address: str = Column(name="Address")
...    gross_income: float = Column(name="Gross-Income")
...
...    @validation_check(selection=["First Name", "Last Name"])
...    def check_is_alphabetic(column: str) -> tuple[Expr, str]:
...        # Anything that is not alphabetic needs to receive the error
...        expression = col(column).str.contains(pattern="/^[A-Za-z]+$/").not_()
...        error = f"{column} can only contain alphabetic characters!"
...
...        return expression, error
...
...    @validation_check(selection=["Gross-Income"])
...    def check_not_negative(column: str) -> tuple[Expr, str]:
...        expression = col(column).lt(lit(0.0))
...        error = f"{column} cannot be lower than 0!"
...
...        return expression, error

Column¶

Each validator should define its column attributes as Column objects.

class glacify.column.Column(name: str, is_identifier: bool = False, nullable: bool = True, allow_duplicates: bool = True, default: str | int | float | bool | list | date | datetime | None = None, format: str | None = None, strict: bool | None = None, min_length: int | None = None, max_length: int | None = None, lt: int | float | date | datetime | None = None, gt: int | float | date | datetime | None = None, le: int | float | date | datetime | None = None, ge: int | float | date | datetime | None = None, equal_to: str | int | float | bool | list | date | datetime | None = None)¶

Represents a column inside a dataframe. Expects at least the full column name as argument (‘name’). A Column contains basic/default validators so that the user does not have to define any of those. For example, the argument ‘min_length’ will add a validation expression to the list of validators, which will then check this column for a certain length. Will only work if the validator is applicable on the annotated python type for this column.

name¶

Name of the column that this Column object represents.

Type:

str

is_identifier¶

This column can be used as identifier for each row/error.

Type:

bool

nullable¶

Column can contain nullable values. By default true.

Type:

bool

allow_duplicates¶

Column allows duplicates to exist. By default True.

Type:

bool

default¶

Replaces all null values with the default value. Be sure to have the same type for the default value just like the annotated type for the column.

Type:

Optional[PythonType]

format¶

Format used to transform date field from strings. Whenever a date/datetime field is found, all values are transformed in to Polars dates via this format. If None, will use Polars’ native default value.

Type:

Optional[str]

strict¶

Determines whether the datatype is strictly set, meaning if true, any wrong datatypes will throw an error. If false, any wrong datatypes will turn in to null. This parameter overwrites ValidationSettings.strict!

Type:

Optional[bool]

min_length¶

Sets the minimal length of iteratable column types, such as strings and lists.

Type:

Optional[int]

max_length¶

Sets the maximal length of iteratable column types, such as strings and lists.

Type:

Optional[int]

lt¶

All values inside the column must be lower than the assigned value.

Type:

Optional[int | float | date | datetime]

gt¶

All values inside the column must be greater than the assigned value.

Type:

Optional[int | float | date | datetime]

le¶

All values inside the column must be lower than or equal to the assigned value.

Type:

Optional[int | float | date | datetime]

ge¶

All values inside the column must be greater than or equal to the assigned value.

Type:

Optional[int | float | date | datetime]

equal_to¶

All values inside the column must be equal to the assigned value.

Type:

Optional[PythonType]

Examples

>>> from polars import Expr, col, lit
>>> from glacify import ValidationBase, Column, validator, ValidationSettings
...
>>> class NewClass(ValidationBase):
...    settings = ValidationSettings(strict=False)
...    index: int = Column(name="Index", is_identifier=True)
...    string_column: str = Column(name="String Column", equal_to="must be equal")
...
>>> # Error:
>>> # The dataframe failed to pass the validation model. Below is a summary of all validation errors:
>>> # 1:
>>> #     String Column must be equal to 'must be equal'!

ValidationSettings¶

The validator allows the user to change model-wide settings.

Settings object that hold the general settings for each validator.

glacify.settings.ValidationSettings.strict¶

If set to true, will force data type validation for each column and throw errors if the type cannot be set. If false, will set all failing cases to ‘null’/None. Defaults to true.

Type:

Optional[bool]

glacify.settings.ValidationSettings.shift_to_row¶

Shifts the entire dataframe to this row. It means that this row must also contain all header new header values, otherwise the model will fail later on. First row starts at index 1.

Type:

Optional[int]
